# nexon command list

Every command nexon understands, grouped by the file it lives in
(`nexon/commands/*.py`). If this list and the code ever disagree, the
code wins - this is just a reference, generated by hand from the
`@command(...)` decorators.

**Wake word:** say "nexon" before any command below, e.g. "nexon volume
up". Say "nexon awake" (or "keep listening"/"always listen"/"start
listen"/"keep listen") to stop needing the wake word each time; say
"sleep"/"go to sleep"/"stop listening" to go back to normal. This part
lives in `nexon/main.py`, not in a commands file.

`<...>` marks a part you fill in when you speak the command.
Phrases on the same line separated by `/` are interchangeable.

## Timer & stopwatch — `commands/timer.py`

| Say | Does |
|---|---|
| "set a timer for `<N>` minutes" / "set a timer for `<N>` seconds" / "set a timer for `<N>` hours" | starts a countdown timer, rings when done |
| "timer for `<N>` minutes" (etc.) | same as above, shorter phrasing |
| "cancel timer" / "cancel timers" / "stop the timer" | cancels all running countdown timers |
| "start timer" / "start stopwatch" | starts the stopwatch |
| "stop timer" / "stop stopwatch" | stops the stopwatch and announces elapsed time |

Any of hour(s)/hr(s), minute(s)/min(s), second(s)/sec(s) work for the unit.

## Volume — `commands/volume.py`

| Say | Does |
|---|---|
| "set volume to `<N>`" / "volume to `<N>`" | sets volume to an exact 0-100 |
| "volume up" / "increase volume" | steps volume up |
| "volume down" / "decrease volume" | steps volume down |
| "mute" | mutes |

## Screen & PDF reading — `commands/screen_reading.py`

| Say | Does |
|---|---|
| "read whatsapp" / "whatsapp messages" / "new messages" | OCRs the WhatsApp Desktop window, reads new text |
| "launch pdf `<name>`" / "open pdf `<name>`" | opens the PDF in your default viewer (name is fuzzy-matched) |
| "read pdf `<name>`" | opens the PDF into nexon's own reader and reads page 1 |
| "read page `<N>`" | reads page N of the currently-open PDF |
| "go to page `<N>`" / "goto page `<N>`" / "jump to page `<N>`" | jumps to page N (reads it aloud if a PDF is loaded; otherwise Ctrl+G in whatever viewer is focused) |
| "next page" / "next slide" | advances one page (PDF-aware; falls back to Page Down) |
| "previous page" / "last page" / "go back a page" / "previous slide" | goes back one page (PDF-aware; falls back to Page Up) |
| "read screen" / "what's on my screen" / "whats on my screen" / "read the screen" | reads the real PDF text if a PDF window is focused, otherwise OCRs the whole screen |

## Email — `commands/mail.py`

| Say | Does |
|---|---|
| "check email" / "check my email" / "check mail" / "check my mail" / "any new emails" / "any new email" | unread count + sender/subject, across every folder in `EMAIL_FOLDERS` |
| "check email in `<folder>`" / "check mail in `<folder>`" | same, just one folder |
| "read email" / "read my email" / "read latest email" / "read my latest email" | reads the newest unread email's full body |

Requires `IMAP_USER`/`IMAP_PASSWORD` set (see README.md) - otherwise
nexon tells you it isn't set up yet.

## Clicking — `commands/click.py`

| Say | Does |
|---|---|
| "click search bar" / "click the search bar" / "click search box" / "click the search box" / "find search bar" | OCR-locates a search box on screen and clicks into it (see `SEARCH_BAR_HINTS` in config.py) |
| "double click `<text>`" | double-clicks the on-screen text that best matches |
| "click `<text>`" | clicks the on-screen text that best matches |

Only works on visible, OCR-readable text - can't click a bare icon.

## Files — `commands/files.py`

| Say | Does |
|---|---|
| "clear recycle bin" / "empty recycle bin" / "clear the recycle bin" / "empty the recycle bin" / "empty the bin" / "clear the bin" / "empty bin" / "clear bin" | empties the Recycle Bin, no confirmation |
| "delete file" / "delete this file" / "delete the file" / "delete" | sends Delete (moves selected item to Recycle Bin) |
| add "permanently" or "forever" to any delete phrase, e.g. "delete this file permanently" | sends Shift+Delete instead (skips the Recycle Bin) |

Assumes the file is already selected on screen (e.g. via "click `<filename>`" first).

## Dictation / typing — `commands/dictation.py`

| Say | Does |
|---|---|
| "send message `<text>`" / "send a message `<text>`" | types text and presses Enter (or listens first if no text given) |
| "type `<text>` and search" | **auto-locates a search bar on screen (OCR), clicks into it**, types, presses Enter - no need to click it yourself first |
| "type `<text>` and enter" | types into whatever field is *already* focused, then presses Enter |
| "type `<text>`" | types into whatever field is already focused (no Enter); if no text is given, listens for it separately |
| "dictate" / "type a message" | prompts "go ahead", listens, then types what you said |

If "type `<x>` and search" can't find anything that looks like a search
box, it tells you and falls back to typing wherever the cursor already is.

## Web browser — `commands/browser.py`

| Say | Does |
|---|---|
| "search `<query>`" | opens a Google search tab AND reads the first result aloud |
| "play `<query>`" / "play `<query>` on youtube" | opens the top YouTube result and plays it |
| "open `<site>`" | opens a site - shortcuts in `SITE_SHORTCUTS` (config.py: youtube, google, gmail, whatsapp, github, facebook, twitter/x, reddit, netflix, amazon, ao3...) or a guessed URL otherwise |
| "close all tabs" | Ctrl+Shift+W |
| "close tab" / "close this tab" / "close the tab" / "close current tab" | Ctrl+W |

## Media — `commands/media.py`

| Say | Does |
|---|---|
| "next video" / "next" | Shift+N |
| "previous video" / "last video" | Shift+P |
| "skip ad" / "skip the ad" / "skip this ad" / "skip ads" (and common mishearings like "skip add") | OCR-finds and clicks a "Skip Ad" button, polling for up to 20s |
| "pause" / "play" | Space (play/pause toggle) |

Note: "pause"/"play" here is a broad, generic check (any command
*containing* "pause" or "play") - it's only reached if nothing more
specific (like "play `<song>`" above, or a browser/dictation phrase)
already matched first.

## System — `commands/system.py`

|---|---|
| "screenshot" / "take a screenshot" | saves a numbered screenshot to `SCREENSHOT_DIR` |

## Adding a new command

Pick the file above that matches what you're adding to, write a
function, decorate it with `@command(...)`, done - see the "How
commands work" section in README.md for the full walkthrough. Please
keep this file updated when you add one, so it stays useful.
